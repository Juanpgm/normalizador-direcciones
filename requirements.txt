# torch is DELIBERATELY NOT LISTED HERE. The deployed service must use the
# CPU-only wheel, which lives on a custom index that requirements.txt cannot
# express without also redirecting every other package. The Dockerfile installs
# it in its own layer:
#
#     pip install --no-cache-dir torch==2.14.0 --index-url https://download.pytorch.org/whl/cpu
#
# `torch==2.14.0` on that index resolves to `2.14.0+cpu`. Measured sizes, not
# estimates: that install is ~930 MB (the image layer, per `docker history`),
# against 3.08 GB for the CUDA build measured in this project's dev environment.
# It is still by far the largest single item in the image, so do not add it here
# and do not let a plain `pip install torch` pull the CUDA wheel into a build.
# The code is device-agnostic: NORMALIZER_DEVICE defaults to "cpu".
